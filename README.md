# Weekly Poll — Telegram-бот еженедельных голосований

Русское пошаговое меню и кнопки для Telegram на iPhone. Бот принимает вопрос, условия и варианты текстом, показывает предпросмотр и отправляет настоящий Telegram-опрос только после нажатия владельцем «✅ Опубликовать». Условия публикуются отдельным сообщением перед опросом. Можно переключать анонимность и несколько ответов. Голосовые сообщения не распознаются.

## Запуск с iPhone

1. Откройте в Telegram официального [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте название и уникальное имя с окончанием `bot`. Сохраните полученный токен в менеджере паролей. **Не отправляйте токен в ChatGPT, GitHub, issues или сообщения своему боту.**
2. Узнайте свой числовой Telegram ID, например у [@userinfobot](https://t.me/userinfobot). Это сторонний сервис: он увидит ваш профиль. Токен ему не нужен. ID не является токеном; username вместо ID не подходит.
3. Откройте в Safari [Render Blueprint](https://dashboard.render.com/select-repo?type=blueprint), подключите этот репозиторий и выберите `render.yaml`. Если экран неудобен, используйте «Запросить настольный веб-сайт» в меню Safari.
4. **Проверьте стоимость перед подтверждением:** конфигурация создаёт платный фоновый worker Starter и постоянный диск 1 GB. Бесплатный засыпающий web service для этого polling-бота не подходит. Хостинг оплачивается отдельно. Если у вас есть сервер, используйте Docker Compose ниже.
5. В защищённых Environment/Secret fields Render введите `TELEGRAM_BOT_TOKEN` и `OWNER_TELEGRAM_ID`. Токен вводите только в секретное поле хостинга. Не добавляйте его в `render.yaml` и не создавайте файл с токеном в репозитории. Остальные переменные заполнены в Blueprint.
6. Запустите сервис. Работать должен **ровно один экземпляр**. Добавьте бота администратором своего канала/группы с правом отправки сообщений и опросов.
7. Откройте личный чат с ботом, нажмите Start, отправьте `/target @имя_канала` (для приватной группы/канала — числовой ID вида `-100…`). Бот проверит свой статус администратора. Если ID неизвестен, его можно узнать через администратора группы или Bot API на своей доверенной машине; не вставляйте токен в адресную строку Safari.
8. Отправьте `/new`, последовательно пришлите вопрос, условия (`-`, если их нет) и 2–10 вариантов, каждый с новой строки. Проверьте место публикации и нажмите «✅ Опубликовать».
9. `/remind_on` включает еженедельное личное напоминание. По умолчанию понедельник, 10:00, Москва. Сам опрос автоматически не публикуется.

Запуск в Telegram пока нельзя считать проверенным без реального токена и работающего хостинга. После развёртывания сначала используйте тестовую группу и проверьте весь сценарий, включая перезапуск сервиса и сохранение черновика. Если Telegram-бот уже используется другим приложением с webhook, сначала остановите прежнее приложение и отключите webhook своим доверенным инструментом; новый процесс намеренно не удаляет его самостоятельно.

## Команды

| Команда | Действие |
| --- | --- |
| `/new` | Новый черновик, заменяет предыдущий |
| `/target @channel` | Задать канал/группу для новых черновиков |
| `/preview` | Повторить готовый предпросмотр |
| `/cancel` | Удалить текущий черновик |
| `/remind_on`, `/remind_off` | Включить/выключить еженедельные напоминания |
| `/help` | Помощь |

Опросы открыты до ручного закрытия в Telegram. Условия не исполняются программно: это текст для участников. Предпросмотр показывает содержание, а не отправляет пробный опрос. При смене места публикации уже созданный черновик сохраняет прежний адресат — он виден в предпросмотре. Если нужно другое место, начните `/new`.

## Настройки окружения

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Секрет из BotFather, обязательный |
| `OWNER_TELEGRAM_ID` | Положительный числовой ID владельца, обязательный |
| `TZ` | IANA timezone, по умолчанию `Europe/Moscow` |
| `REMINDER_WEEKDAY` | 0 — понедельник … 6 — воскресенье |
| `REMINDER_HOUR` | Час 0–23, по умолчанию 10 |
| `DATABASE_PATH` | `/data/polls.sqlite3`, обязательно постоянное хранилище |

Напоминание отправляется один раз в выбранный день после указанного часа. Если сервис весь день выключен, пропущенное напоминание не догоняется. Напоминания выключены до `/remind_on`.

## Собственный сервер

Нужны Docker и Compose. Передайте обе обязательные переменные из секретного хранилища сервера в окружение процесса, затем `docker compose up -d --build`. Не вводите токен литералом в команду, сохраняемую в истории shell. Named volume хранит SQLite между перезапусками; не удаляйте его через `down -v`. Делайте резервные копии диска. Для Render создаётся persistent disk; проверьте права записи в `/data` при первом запуске.

Python 3.12+, внешние Python-зависимости отсутствуют. Локально: `python -m unittest discover -s tests -v`. Прямой запуск: `python bot.py` с теми же защищёнными переменными окружения.

## Надёжность и безопасность

Доступ разрешён только указанному ID и только в личном чате. Не используется присвоение прав «первому написавшему». Черновик, адресат, настройки и offset Telegram сохраняются в SQLite. Токен не пишется в журнал; HTTP-ошибки выводятся без URL запроса. При утечке перевыпустите токен через BotFather и замените секрет на хостинге.

Двойное нажатие и старые кнопки не создают повторную публикацию. Перед сетевой отправкой черновик блокируется. Если результат отправки неизвестен (например, обрыв сети или перезапуск), повторной отправки нет: проверьте канал вручную и при необходимости создайте новый черновик. Telegram не поддерживает атомарную отправку условий и опроса: при сбое условия могут оказаться опубликованы без опроса. Входящее обновление отмечается обработанным до выполнения, поэтому при аварии отдельное сообщение может потребоваться отправить повторно. SQLite должен использоваться одним процессом.
